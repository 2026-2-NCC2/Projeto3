## 📌 Descrição

O TrocaTicket é uma plataforma web desenvolvida para otimizar o planejamento, a gestão e a realização de eventos de médio e grande porte. A aplicação atua como um ecossistema integrado que conecta organizadores de eventos e fornecedores de serviços em um único ambiente colaborativo. O sistema permite que o organizador estruture o evento definindo parâmetros de público e margem de lucro, gerencie rubricas orçamentárias e receba cotações e propostas comerciais competitivas de diferentes fornecedores. Para o público final, a plataforma centraliza a descoberta de eventos, a compra simplificada e o acesso digital aos ingressos.
